## 已知约束

- **识别关键词不翻译**：中文课表匹配用的关键词（周一 / 第1-2节 / 单双周 / 休息 等）刻意保留中文并加了源码注释
- **闹钟备注是用户数据**：切换界面语言不会改写已保存的备注（新建的会按当前语言生成）
- **数据库 schema 不进正式包**：`app/schemas/` 只打到 debug/test 的 assets，供 Robolectric 迁移测试读取
- **签名不可更换除非卸载重装**：换新密钥会导致已安装版本无法覆盖更新；只换密码不影响（见签名文档）
